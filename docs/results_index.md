# Results index

Numbered inventory of the active v2 outputs under `results/`, in pipeline
order. Row counts exclude the header line and reflect the 2026-11-05 run.

Four numbering schemes are used:

- `#n` — output file or directory; the number is also the on-disk filename
  prefix (`01_comparison/`, `02_gene_structure_registry.tsv`, ...).
- `Rn` — Snakemake rule (Appendix A); the rule files are numbered
  `workflow/rules/01_registry.smk`–`07_dna.smk`.
- `Sn` — script or Python module (Appendix B).
- `Dn` — dataset declaration (Appendix C), defined in the `DATASETS` block at
  the top of `workflow/rules/02_pae.smk`.

Canonical deliverables: **#2** (`02_gene_structure_registry.tsv`) and **#9**
(`09_segments.tsv`). Everything else is an intermediate or a diagnostic.

### 2. Gene structure registry

Producer: **R2** `build_registry` → **S1** `scripts/afdb_domains.py` →
**S3** `src/cli.py` → **S5** `src/registry.py`
→ `results/02_gene_structure_registry.tsv`

5,142 rows. One row per gene, recording the selected structure, PAE matrix,

Producer: **R2** (same rule as #2) → `results/03_registry_summary.tsv`

9 rows. Gene counts grouped by `selection_reason` and `structure_source`.

## Curated branch

Every step below reads the registry (#2) and feeds the next step.

### 4. Raw PAE domains

Producer: **R3** `registry_pae_to_domains` → **S1** → **S3** → **S6** `src/pae.py`
→ `results/04_domains/`

5,120 `.domain` files, one per analysed gene.

### 5. PAE domain table

Producer: **R4** `registry_domains_to_table` → **S1** → **S3** → **S6**
→ `results/05_PAE_domain.tsv`

30,757 rows. The `.domain` files (#4) collapsed into one table.

### 6. pLDDT table

Producer: **R5** `registry_extract_plddt` → **S1** → **S3** → **S7** `src/plddt.py`
→ `results/06_pLDDT_scores.tsv`

5,119 rows. Per-gene, per-residue confidence scores.

### 7. Merged PAE + pLDDT table

Producer: **R6** `registry_merge_domains` → **S1** → **S3** → **S8** `src/segments.py`
→ `results/07_reformated_PAE_domain.tsv`

17,843 rows. Domain intervals joined to their pLDDT statistics.

### 8. Annotated domain table

Producer: **R7** `registry_assign_type` → **S1** → **S3** → **S8**
→ `results/08_annotated_PAE_domain.tsv`

17,843 rows. Adds the segment type (`disordered`, `structured`, and so on).

### 9. Unified segment table

Producer: **R8** `registry_unify_segments` → **S1** → **S3** → **S9** `src/unify.py`
→ `results/09_segments.tsv`

42,178 rows: PAE 20,711 + TED 11,983 + ECOD 9,484. This is the final delivery
table; coordinates are 1-based inclusive.
